# Lab Validation Skill

1. Read experiment requirements.
2. Inspect the implementation.
3. Check imports and syntax.
4. Validate important inputs and outputs.
5. Test representative and edge cases.
6. Check algorithmic correctness.
7. For ML, verify dataset isolation and metrics.
8. Run executable checks when possible.
9. Distinguish verified outcomes from assumptions.
10. Report errors with corrective recommendations.

A program is not considered successfully tested
unless the appropriate commands were executed.
