# Lab Implementation Skill

1. Read `docs/EXPERIMENT_SPEC.md`.
2. Inspect `docs/PLAN.md` and `docs/ARCHITECTURE.md`.
3. Identify required libraries and inputs.
4. Implement the smallest correct solution.
5. Prefer one self-contained Python file.
6. Keep the script compatible with Google Colab.
7. Explain important operations using comments.
8. Include the experiment's required outputs.
9. Execute suitable checks.
10. Report actual results and limitations.

Do not create unnecessary package structures.
Do not fabricate observations or accuracy.
